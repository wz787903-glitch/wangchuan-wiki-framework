# 架构与边界

## 目录

- `src/data.ts`：虚构资料、课程、问题和成员示例。
- `src/main.tsx`：资料页、课程阅读器、答题页、小队选择、共创草稿。
- `src/quiz.ts`：答题、跳题、进度恢复与评分；不依赖 React。
- `src/storage.ts`：本地存储封装，存储失败时向用户显示提示。
- `tests/quiz.test.ts`：覆盖自动跳题、旧事件、错误记录与显式提交等行为。
- `scripts/check-public.mjs`：公开文件范围、文本编码、媒体文件及常见凭据模式检查。

导航采用 hash，四个页面互相独立。切换页面后，收藏、阅读和答题从浏览器记录恢复；小队选择和未保存的表单输入仅保留在当前页面。

## 从社区百科抽出的交互

保留课程的“选中答案后进入下一道未答题、显式提交、查看解析”流程，去掉具体游戏题库与课程正文。答题函数拒绝已切走题目的旧事件，避免连续输入误选下一题。结果解析默认折叠，窄屏上可以直接切换其他章节。

资料检索、收藏、成员替换和本地草稿重新整理为小型独立示例。没有复制原站路由、后端、权限配置、数据目录和历史记录；它不是原站的完整可部署镜像。

## 接入正式社区

本地草稿可以作为编辑器原型。若接入投稿服务，应由服务端负责提交、作者权限、审核状态、通知和修改记录，不能根据浏览器传来的“已审核”字段决定发布。

课程进度和收藏可以继续只保存在本地，也可以接入账号同步。需要同步时，请定义明确的数据版本与冲突处理规则，并让用户知道数据的保存位置。

公开检查脚本是防止误带文件的辅助工具，不能自动确认内容版权或替代人工审阅。新增目录需要维护允许列表，新增依赖需要核对许可证。
